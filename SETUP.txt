Upload these FOUR files directly to the ROOT of your GitHub repository:
index.html
logo.png
database.sql
SETUP.txt

VERCEL
1. Create a private GitHub repository.
2. Upload all four files directly to repository root. Do not create a folder.
3. Import the repository in Vercel and deploy. Static HTML; no build command needed.

SUPABASE
1. Create a Supabase project.
2. SQL Editor → New Query → paste database.sql → Run.
3. Project Settings → API: copy Project URL and anon/public key.
4. In index.html, replace PASTE_SUPABASE_PROJECT_URL and PASTE_SUPABASE_ANON_PUBLIC_KEY in const cfg.
5. Use ONLY anon/public key in index.html. Never put service_role key there.
6. Upload changed index.html to GitHub; Vercel redeploys.

ADMIN
1. Supabase Authentication: disable public sign-ups.
2. Authentication → Users → Add user: create the institution admin account.
3. Open https://YOUR-DOMAIN.vercel.app/#admin and sign in.

GOOGLE SHEETS MIRROR (optional)
Supabase remains the main database. Create a private Google Sheet → Extensions → Apps Script, paste:

function doPost(e) {
 const payload=JSON.parse(e.postData.contents||"{}");
 const d=payload.record||payload;
 const ss=SpreadsheetApp.getActiveSpreadsheet();
 const sh=ss.getSheetByName("Admissions")||ss.insertSheet("Admissions");
 if(sh.getLastRow()===0)sh.appendRow(["Application No","Date","Student","DOB","Father","Mother","Address","Phone","District","Status"]);
 sh.appendRow([d.application_no,d.created_at,d.name,d.dob,d.father_name,d.mother_name,d.address,d.phone,d.district,d.status]);
 return ContentService.createTextOutput("OK");
}

Deploy Apps Script as Web App (execute as you). In Supabase → Database → Webhooks create a webhook for table public.admissions, INSERT event, HTTP POST, and paste the Apps Script URL. Test one application and check both stores. Keep the Sheet private and treat the webhook URL as sensitive.

IMPORTANT
- Submission receipt is not admission approval; parent saves it using browser Print → Save as PDF.
- Aadhaar is not collected. Student photos are private in Supabase Storage.
- Verify contact number and eligibility details before launch.
- Test with dummy application data before public promotion.
